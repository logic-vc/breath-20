### 1-2. UX 공백

- **화면을 계속 봐야 하는 구조**: 20초짜리 들숨을 화면만 보며 따라가면 집중이 깨집니다. 단계 전환을 알리는 소리·진동 신호가 없습니다.
- **처음부터 20초 들숨**: 입문자는 대부분 실패합니다. 단계별 난이도가 없습니다.
- **세션 개념이 없음**: 1사이클(43초)만 하고 끝나며, 반복 횟수를 고를 수 없습니다.
- **일시정지 없음**, 연습 중 **화면 꺼짐**(Wake Lock 미사용).
- **피드백 부족**: 끝나도 "완료!"만 뜨고 성취감이나 변화가 보이지 않습니다.
- **앱다움 부족**: 설치(PWA), 오프라인, safe-area(노치), 하단 탭 내비게이션이 없습니다.
- 접근성: 스크린리더 안내, `prefers-reduced-motion` 대응이 없습니다.

## 2. 레퍼런스 분석 (카테고리 상위 앱)

| 앱 | 강점 (가져올 것) | 약점 (우리의 기회) |
|----|-----------------|-------------------|
| **Calm** | 몰입형 다크 그라데이션, 크고 느린 타이포, "Breathe Bubble"의 단순함 | 호흡은 부가 기능이라 리듬 커스텀·성장 요소가 약함 |
| **Headspace** | 따뜻한 일러스트, 친근한 문구, 온보딩 | 호흡 전용 트레이닝 깊이 부족, 구독 장벽 |
| **Breathwrk** | 단계별 링 프로그레스, 패턴 라이브러리, 연속 기록(streak) | 화면을 봐야 따라가는 UI, 정보량이 많음 |
| **Oak** | 미니멀, 무료, 세션 후 통계 | 비주얼이 밋밋하고 정서적 보상이 약함 |
| **Open / Othership** | 고급스러운 사운드 디자인, 감정 체크인 | 고가 구독, 초보자에게 진입 장벽 |

**공통 패턴 → v2에 반영**
1. 세션 중에는 크롬(헤더/탭)을 숨기는 **몰입 모드**
2. 링 프로그레스로 **사이클 내 위치**를 한눈에 표시
3. 홈 → 기록 → 설정의 **하단 탭 3개**
4. 세션 종료 시 **요약 카드**(성취감)
5. **Streak + 캘린더 히트맵**으로 습관 형성

> 참고: 위 분석은 각 앱의 공개된 디자인 패턴을 기준으로 정리했습니다. 출시 전 최신 버전 스크린 리서치로 업데이트를 권장합니다.

## 3. 포지셔닝 & USP

**타깃**: 잠들기 전이나 업무 중간에 3~5분 동안 마음을 가라앉히고 싶은 20~40대. 명상 앱은 부담스럽지만 "숨 쉬기"는 해볼 만하다고 느끼는 사람.

**포지셔닝**: "명상 앱"이 아닌 **"느린 호흡 트레이너"**. 콘텐츠 소비가 아니라 **숨의 길이가 실제로 늘어나는 경험**을 판다.

### USP ① 눈 감고 하는 호흡 (Eyes-closed Guidance)
- 배경음이 **호흡과 함께 숨 쉽니다**. 들숨에는 필터가 열리며 소리가 밝고 커지고, 멈춤에서는 머무르고, 날숨에는 어둡고 잔잔해집니다.
- 단계 전환마다 **음정이 다른 차임**(들숨↑ / 멈춤 / 날숨↓)과 **진동 패턴**이 울립니다.
- → 화면을 보지 않아도 따라갈 수 있습니다. 대부분의 경쟁 앱은 "보는 UI"입니다.

### USP ② 숨길 사다리 (Breath Ladder)
- 6·2·6 → 10·2·10 → 15·3·15 → **20·3·20(목표)**의 4단계.
- 같은 단계를 **3번 완주하면 다음 단계를 추천**합니다. 기록 탭에서 사다리 진행도를 볼 수 있습니다.
- → "20초 들숨"이라는 어려운 목표를 **성장 서사**로 바꿉니다.

### USP ③ 마음 변화 기록 (Calm Delta)
- 세션 전후 1탭 체크인(긴장 ↔ 평온, 5단계).
- 요약 카드와 기록 탭에서 **"평균 +1.4 편안해졌어요"**를 보여줍니다.
- → "효과가 있다"는 개인 데이터 기반 증거가 리텐션의 핵심 동기가 됩니다.

### 기반 가치: 프라이버시 & 오프라인
- 계정, 서버, 추적이 없고 모든 기록은 기기에만 저장합니다. 오프라인에서도 완전히 동작합니다(PWA).

## 7. 리스크 & 대응

- **안전**: 매우 느린 호흡이나 숨 참기는 어지러움을 유발할 수 있습니다. 온보딩과 설정에 "불편하면 즉시 멈추고 평소대로 숨 쉬기" 안내를 넣었고, 사다리 입문 단계를 제공합니다. 의료 효능은 주장하지 않습니다.
- **iOS 제약**: 웹 진동 API가 없고 백그라운드 오디오가 제한됩니다. M2 네이티브 래핑으로 해결합니다.
- **데이터 유실**: localStorage는 브라우저 데이터 삭제 시 사라집니다. JSON 내보내기를 제공하고, 추후 iCloud/Drive 백업을 검토합니다.

## 8. v2.1 업데이트 — 레퍼런스 스타일 UI + 마이크 호흡 훈련

### 디자인 (v2.2 — 독자 스타일)
> v2.1은 레퍼런스(Headspace)와 지나치게 비슷해 한글판처럼 보였다. 캐릭터·크림 카드·곡선 웰컴·아래에서 차오르는 물결을 모두 제거하고 아래 원칙으로 재설계.
- **흰 배경 + 얇은 선 + 장식 없는 UI.** 일러스트·마스코트 없음. 버튼은 잉크색(거의 검정) 알약.
- **호흡 화면**: 가운데 형태가 **부풀고 꺼진다**(작은 점 ↔ 큰 원). 가득 찼을 때의 크기를 점선 가이드로 표시. 아래에 단계명·남은 초.
- **색**: 블루(빈 상태) → 라벤더 → 피치 → **주황(가득 찬 상태)** → 다시 블루. 색은 숨 진행도(`--p`)의 함수.
- **호흡 모양 2종(설정에서 선택)**: A. 원 / B. 블롭(가장자리가 살아 숨 쉬듯 일렁임).
- **홈**: 홈 화면 자체가 호흡 미리보기(천천히 부풀었다 꺼지는 형태) → 시작 버튼 → 리듬·반복 선택.

### 마이크 호흡 훈련 (훈련 탭)
| 훈련 | 모티브 | 방식 |
|------|--------|------|
| 공 띄우기 | 인센티브 스피로미터(공 3개) | 숨소리 세기에 따라 약·중·강 공이 차례로 떠오름. 3개를 2초 유지하면 ⭐ |
| 일정하게 마시기 | Coach 2 | 목표 구간(초록) 안에서 세기를 3초 일정하게 유지하면 ⭐ |

- **원리**: 마이크 → 고역/저역 필터 → 소리 크기(dB) → 개인 보정(조용할 때/힘껏 쉴 때)으로 0~1 정규화. 5회 1세트.
- **한계(정직하게)**: 실제 호흡량(mL)·유속을 재는 것이 아니라 *숨소리 크기로 본 상대적 세기*. 코로 조용히 쉬면 소리가 약하고, 들숨/날숨은 구분하지 못함. 마이크 보정(주변 소음, 최대 세기)이 필요하며, 소리가 너무 작으면 안내.
- **프라이버시**: 소리는 기기 안에서만 분석. 녹음·저장·전송 없음. 탭을 벗어나거나 앱이 가려지면 마이크 즉시 종료.
- **마이크 없이 체험**: 화면을 길게 눌러 불기 (권한 거부·데스크톱용).
- **다음 후보**: 카메라로 가슴/어깨 움직임을 보는 호흡 감지(온디바이스 모션 분석), 기기(스피로미터) 연동.
